# 维护指南

这个项目刻意把「会变的东西」和「逻辑」分开了：

- 频道变了 → 只改 `config/channels.toml`
- 数据源变了 → 只改 `config/settings.toml`
- 解析逻辑 → `epg/providers/`，一般不用动

---

## 1. 新增一个频道

### 1.1 先确认它在哪个源里

**央视 / 卫视**（`xmltv-51zmt`）：先搜上游有没有这个频道名

```bash
python -m epg resolve --source xmltv-51zmt --keyword 江苏
```

输出形如：

```
匹配 "江苏" 的频道（2）：
  江苏卫视
  江苏体育
```

把找到的名字原样填进 `ref`。

**江苏地方台**（`tvmao`）：先列出江苏省所有可抓频道

```bash
python -m epg discover --province 320000
```

输出可以直接粘：

```toml
{ id = "js-city", name = "江苏城市", source = "tvmao", ref = "JSTV-JSTV3" },
```

> 省份代码：江苏 `320000`、浙江 `330000`、广东 `440000`、北京 `110000`、上海 `310000`……
> 想抓别的省，把 `settings.toml` 里的 `[[sources]]` 复制一份、换个 id 即可。

**整包 XMLTV 里没有的杂项频道**（`diyp-51zmt`）：直接用频道名查一天试试

```bash
curl "http://epg.51zmt.top:8000/api/diyp/?ch=东方财经&date=2026-11-18"
```

返回里 `channel_name` 不等于「未提供」，就说明能抓，`ref` 填这个名字即可：

```toml
{ id = "df-caijing", name = "东方财经", source = "diyp-51zmt", ref = "东方财经" },
```

### 1.2 写进注册表

打开 `config/channels.toml`，在对应 `groups` 的 `channels = [ ... ]` 里加一行：

```toml
{ id = "js-city", name = "江苏城市", source = "tvmao", ref = "JSTV-JSTV3" },
```

| 字段 | 规则 |
| --- | --- |
| `id` | 全局唯一，小写字母/数字/短横线。**发布后不要再改**，播放器靠它匹配频道 |
| `name` | 显示名，随便改名，不影响数据 |
| `source` | `settings.toml` 里已有数据源的 id |
| `ref` | 数据源里的原始频道名（xmltv）或频道代码（tvmao） |
| `alias` | 可选，别名数组，用于和外部播放列表对齐，如 `alias = ["江苏体育休闲"]` |

### 1.3 验证

```bash
python -m epg validate            # 检查 ref 是否还能在上游找到
python -m epg build --days 1      # 实跑一遍
```

`validate` 会给出「最接近的名字」提示，通常就是上游改名了。

## 2. 上游改版 / 频道失效怎么办

现象：`python -m epg build` 的「无节目数据」列表里出现某频道，或 `validate` 报错。

排查顺序：

1. **上游改名**（最常见）—— 跑 `resolve` 找新名字，改 `ref`。
2. **上游当天没数据** —— 单日可能确实为空（比如某些频道只提前一天出表），换一天再试：
   `python -m epg build --days 3`。
3. **页面结构变了** —— `epg/providers/tvmao.py` 里 `_ITEM_RE` 需要跟着改；
   HTML 结构说明写在该文件顶部的注释里。
4. **整包 XMLTV 地址变了** —— 改 `config/settings.toml` 里的 `url`。

想彻底换一个源：在 `settings.toml` 新增 `[[sources]]`，然后在 `epg/providers/` 下写一个
`Provider` 子类（继承 `base.py`，实现 `fetch()`），最后在 `providers/__init__.py` 的
`PROVIDERS` 里注册。其余代码无需改动。

## 3. 播放列表的 tvg-id 对不上怎么办

这是最常见的问题：播放器按 `tvg-id` 匹配节目单，两边 id 写法不一致就全都没节目。

```bash
python -m epg patch-m3u http://192.168.3.1:8189/unicompublic.m3u --verbose
```

输出 `dist/unicompublic.epg.m3u`，把播放器里的地址换成这个文件即可。

工具匹配顺序：

1. `tvg-id` 完全相同
2. `tvg-id` 忽略大小写 —— `CCTV1` → `cctv1`
3. 命中注册表 `alias` —— `CCTV5+` → `cctv5plus`
4. `tvg-name` / 频道显示名完全相同 —— `北京卫视` → `sat-beijing`
5. 去掉 HD/4K/空格/横线后相同 —— `CCTV-5+HD 体育赛事` → `cctv5plus`
6. 一方包含另一方 —— `优漫卡通` → `js-cartoon`

如果要加的新频道经常被同一个错写法坑到，就在 `channels.toml` 里给它加 `alias`，
比在代码里写特例干净。

`dist/*.report.json` 里有逐条对齐结果，未对齐的条目通常就是节目单没收录的频道
（播放器不显示节目，但播放不受影响）。

## 4. 一次性批量改频道

`config/channels.toml` 是纯文本，可以用脚本批量生成，例如把 `discover` 的输出
直接写进文件：

```bash
python -m epg discover --province 320000 > /tmp/js.txt
```

然后手工整理一下粘进 `channels = [ ]` 即可。保持一频道一行，方便 diff。

## 5. 数据口径

生成前所有节目都会过一遍 `epg/normalize.py`：

| 处理 | 说明 |
| --- | --- |
| 去广告尾巴 | 上游会在标题后加 `--免费使用`，会被去掉 |
| 去占位 | 含「暂未提供 / 暂无节目 / 精彩节目」的条目不输出 |
| 排序 | 按开始时间升序 |
| 去重 | 同频道同开始时间同标题只保留一条 |
| 补结束时间 | tvmao 只给开始时间，用下一条的开始时间推算，最后一条 +60 分钟 |

时区固定 `Asia/Shanghai`，所有时间带 `+08:00`，跨机器、跨 CI 都不会漂。

## 6. 自动化说明

`.github/workflows/update.yml`：

- 定时：每天 06:30（北京时间）
- 手动：Actions → Update EPG → Run workflow
- 抓取失败时不会覆盖上次成功的结果（脚本直接退出，不写文件）

提交内容是 `dist/` 和 `data/archive/<日期>/`，历史快照方便回溯「昨天到底播了什么」。

如果仓库连续几天没有新 commit，通常是上游挂了或改名了，按第 2 节排查。

## 7. 常见问题

**Q：为什么央视/卫视只有 1~2 天，江苏地方台有好几天？**
数据源能提供多久就是多久。XMLTV 源通常给今天+明天，电视猫的周表能到 7 天。
`dist/epg.json` 里每个频道都有 `coverage` 字段说明实际覆盖范围。

**Q：能加别的省吗？**
可以。复制一份 `[[sources]]`、换个 id、`--province` 改成对应省份代码，
再建一个 `group` 就行，代码不用改。

**Q：JSON 里的 `episode` 是什么？**
从标题里拆出的期号，如 `今日说法-2026-209` → `title_base: 今日说法`、`episode: 2026-209`，
方便你自己做「只看某一期」之类的功能。
